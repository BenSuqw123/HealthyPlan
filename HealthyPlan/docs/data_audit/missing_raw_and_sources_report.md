## Priority interpretation

- **Blocks the project now:** missing dish ingredient/raw recipe layer; missing complete transformation pipeline for thesis reproducibility.
- **Blocks medically credible use but not a clearly labeled prototype demo:** incomplete health-rule evidence, absent human RAG review, missing exercise contraindication review.
- **Can be used temporarily with explicit limitations:** USDA-derived food rows with valid source IDs, exact MET rows, and structurally valid RAG data, provided invalid/unreviewed records are excluded and no diagnosis/treatment claims are made.
